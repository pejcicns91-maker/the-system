# CB12 PROTOCOL — THE MORNING JUDGMENT LAYER (binding addition to RUN_BRIEF, 2026-07-15)
After the brief and the wall payloads, the AI running the session MUST produce, per coin:

## 1. THE MORNING READ (printed, 3–6 plain sentences)
What is actually unusual today: calendar events inside the 08:00–14:00 window, overnight tape
and headlines, cross-coin divergences, regime flips brewing, where judgment disagrees with the
mechanical lines. If nothing is unusual, say so — never manufacture insight. This section is
JUDGMENT, not template. It is graded implicitly by the forward register.

## 2. THE ZONE PLANS (appended to each coin's payload as S-fields)
For each shortlisted wall (contact ≥50% or price within 1U):
  S{n}:{conf},{up|down},{tgt};{altConf},{altTgt},{quitPx};{brkPx},{brkConf},{brkTgt};{failPx}
Composition rules: base branch = live scenario states × day-type × regime × tape, confidences
composed FROM banked odds (labeled reads, not certifications); all targets/triggers in PRICES;
brkPx ≈ zone edge + 0.6U (the point of no return, 79% banked); failPx = the price that says the
push died (judgment); if today's captures are sub-1% at funded friction, the plan must say
watch-don't-trade honestly. Plain voice only — the renderer speaks these as sentences.

## 3. THE NUANCE LINE (payload field N:)
One sentence of the thing the odds can't say. Example:
  N:SOL lagging a risk-on tape — an upside break is catch-up, respect it
## 4. OVERRIDE (payload field OVR:) — none | EXPANSION | QUIET (from the brief's day-type)

## MIDDAY RE-LOOK (standing offer, user-initiated)
Any time: "recheck {coin}" (or a screenshot) → re-fetch live data, re-read tape, re-issue that
zone's plan in the same grammar. The chart holds the morning's judgment; the AI stays on call.

# AUDIT CONTRACT — binds any AI producing research or trade output for Svet

## THE PHRASE (copy-paste, anytime, any topic):
**AUDIT: prove it — full contract.**

Pasting that phrase obligates the AI to deliver ALL nine items below in one reply, for the most recent claim/study/output (or the topic named after the phrase). No negotiation, no partial delivery without downgrade.

## THE NINE ITEMS

1. **Prereg-first.** Show the pre-registration file that existed BEFORE measurement. List every deviation between prereg and what actually ran. No prereg = the result is VOID, said in bold.
2. **Rerun-ability.** Every artifact file listed with: row count, SHA-256 hash, the ONE exact command that regenerates it, and the fixed random seed. A rerun must reproduce the headline numbers exactly.
3. **n beside every %.** Every percentage on screen carries its sample size. Anything under 40 events is labeled UNDERPOWERED, never "killed" and never "works."
4. **Baseline beside every headline.** Each headline number sits next to its base rate / placebo / random-entry equivalent. A number with no opponent is not evidence.
5. **4+ spot-checks I can see with my own eyes.** Concrete events as coin · date · time · price, checkable on a TradingView chart — and AT LEAST ONE must be a failure case (a loss, a miss, a stop-out). Winners-only spot-checks = violation.
6. **Full history + decomposition.** The headline is computed on ALL data (weekends included), and beside it: per-year, per-Hayden-regime, per-asset, weekday/weekend. Instability across splits is reported as a regime marker, not hidden.
7. **Money-claim status stamped.** Every P&L number carries one of: DISCOVERY (unsealed) / SEALED-PASS / LIVE-VALIDATED (v1.2 chain cited). Dual cost rows (frictionless + FTMO friction). The words "validated," "proven," or "edge" are forbidden without SEALED-PASS or better.
8. **DROPPED section.** Everything descoped, skipped, or changed since the work was commissioned, listed explicitly — even if empty ("DROPPED: nothing"). A missing DROPPED section is itself a violation.
9. **Downgrade clause.** Any item the AI cannot produce → the affected claim is downgraded to **UNVERIFIED** in bold, in the same message, with no defense attached.

## VERDICT
Svet replies **PASS** or **FAIL <item numbers>**. A FAIL is redone in full, without argument. Repeated FAIL on the same item = the underlying work is treated as untrusted and re-run from the prereg.
